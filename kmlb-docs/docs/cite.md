<h2 class="kmlb-hero__title">Cite KMLB</h2>
<p class="kmlb-hero__sub">If KMLB supports your research or published work, a citation is appreciated. It is not required under the MIT license, but documented use builds trust in the tool.</p>
</div>

Pick a format below. Each is generated for the current release. Run
`pip show kmlb` to confirm the version used.

## APA

```text
Mros, H. F., III. (__KMLB_YEAR__). KMLB: KML builder [Computer software]. Version __KMLB_VERSION__. https://pypi.org/project/kmlb/
```

## Chicago

```text
Mros, Henry F., III. __KMLB_YEAR__. KMLB: KML Builder. Version __KMLB_VERSION__. Computer software. https://pypi.org/project/kmlb/
```

## BibTeX

```bibtex
@software{KMLB,
  author  = {Mros, III, Henry F.},
  title   = {KMLB: KML Builder},
  year    = {__KMLB_YEAR__},
  version = {__KMLB_VERSION__},
  url     = {https://pypi.org/project/kmlb/}
}
```
